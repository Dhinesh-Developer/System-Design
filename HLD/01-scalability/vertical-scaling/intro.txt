1. Vertical Scaling
What is it?
Vertical scaling means:

Make one server more powerful.

Before:

Server
2 CPU
4 GB RAM

        ↓ Vertical Scaling

Server
8 CPU
16 GB RAM

Important idea

Vertical scaling:
ONE SERVER
    ↓
More CPU
More RAM
Faster hardware

Limitation

There is a physical limit.
You cannot keep doing:

8 GB
16 GB
32 GB
64 GB
128 GB
...

forever.

That's where horizontal scaling becomes important.
